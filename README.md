# Radar Foodtech

Publicação independente sobre tecnologia, operação e qualidade de software no mercado de alimentação.

## Proposta

Analisar foodtechs além da lista de funcionalidades, considerando confiabilidade, experiência do usuário, integração e impacto na operação real.

## Publicação

O site utiliza Jekyll e GitHub Pages. Os artigos ficam na pasta `_posts` em formato Markdown.
